Deployment & Git Gateway Setup Guide

Follow these 3 simple steps to integrate Decap CMS directly into your static website without requiring a complex backend database.

1

Create `/admin/index.html`

Create an `admin` folder in your website root containing `index.html` to load Decap CMS via CDN. `admin/preview.js` embeds the actual `index.html` site in the CMS preview and sends the current draft content to it, so layout and styling come from the customer-facing page. The preview registers `site.css` with Decap, and the embedded site loads its own full stylesheet and scripts.

<!DOCTYPE html>
<html>
<head><title>Content Manager</title></head>
<body>
  <script src="https://unpkg.com/decap-cms@^3.0.0/dist/decap-cms.js"></script>
  <script src="/admin/preview.js"></script>
</body>
</html>
2

Add `config.yml`

Copy the YAML block from Tab 1 into `admin/config.yml`. Make sure `media_folder` matches your image directory.

your-website/
├── index.html
├── admin/
│ ├── index.html
│ └── config.yml
└── content/
3

Enable Authentication

For local editing, run $env:PORT='8082'; npx decap-server in PowerShell and keep local_backend enabled. Before deploying, remove local_backend. For Netlify hosting, enable Git Gateway under Site Settings > Identity, or configure Decap GitHub OAuth.

Read Decap Auth Specs

Dynamic Frontend Content Integration

Use this standard JavaScript snippet in your main `index.html` to fetch content updated by Decap CMS:

index.html (Fetch Estimator Surcharges & Poodle/Doodle Rule) 
// Fetch Estimator Configuration generated by Decap CMS
async function loadCMSData() {
    try {
        const response = await fetch('/content/estimator.json');
        if (response.ok) {
            const estimatorData = await response.json();
            
            // Example: Access Poodle/Doodle Surcharge ($20 default)
            const doodleCoat = estimatorData.coats.find(c => c.id === 'doodle');
            console.log("Poodle/Doodle Surcharge:", doodleCoat.extra_cost); // Returns 20
        }
    } catch (err) {
        console.warn("Using fallback local rates:", err);
    }
}

window.addEventListener('DOMContentLoaded', loadCMSData);
